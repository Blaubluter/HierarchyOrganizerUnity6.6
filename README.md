# Hierarchy Organizer 2.2 for Unity 6.6

Unity editor tool for organizing scene objects and prefab folders in dedicated tabs.

## Version 2.2

- Separate, independently dockable Hierarchy Tabs and Project Tabs windows
- Shared organizer state across both windows
- Optional prefab previews with GPU preview ON/OFF control
- Preview priorities: Low, Medium, High, and unthrottled Ultra
- GPU preview controls remain visible while prefab content scrolls
- Safe icon-only startup mode for systems with sensitive graphics drivers

Open the windows from `Window > Hierarchy Organizer` in Unity.
